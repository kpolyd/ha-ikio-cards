# Ikio logo

`ikio-logo.png` is the approved original option B, preserved from the design preview. Four rounded tiles with unequal sizes form a house silhouette. The house refers to the name's origin in Greek οικία; the tiles represent the dashboard cards. Preserve the asymmetric proportions, gaps, roof angles and corner shapes when producing future variants. Colour alone should not distinguish the mark.

The root README displays this artwork using an absolute raw GitHub URL so it can render in GitHub and the HACS repository details page. The URL becomes available after these files are published to main.

HACS dashboard repositories use a category icon in the listing. The HACS frontend reserves brand listing images for integration repositories; a logo file or an unsupported `icon`/`logo` manifest key cannot replace the dashboard category icon. Do not turn Ikio into an integration or change its installation type to work around this.
