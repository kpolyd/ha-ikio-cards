# Ikio graph renderer

Shared by Graph and Electricity. Uses the approved soft mint/green/yellow/amber/coral/red/orchid palette at the original ten normalized positions, with encoded sRGB interpolation. Users set only expected minimum/maximum. History uses HA's authenticated `history/history_during_period` WebSocket command. No recorder means a readable live-state card with a history error message. Requests are deduplicated per connection/minute; offscreen/hidden refresh pauses. Obsolete results are ignored. Peak/gap-preserving samples are bounded; colours follow values and never clip outliers.

`graphPalette(theme, hass)` returns the dark palette or its deeper light equivalent; HA appearance follows `hass.themes.darkMode`. HistoryCard shares this choice with Electricity device/Untracked sparklines. The renderer accepts optional `colourStops`; `colour` accepts the same palette as its fourth argument. Server Monitor uses the mint and orchid endpoints as fixed download/upload series colours, preserving its existing solid/dashed encoding. Categorical distribution rings and resource status thresholds are unchanged.

Electricity requests observed min/mid/max axis labels, subtle dashed guides and a display-only axis formatter. Guides and label positions use the same unrounded value scale. Colour bounds and plotted points are unchanged. Constant history uses one guide, and a midpoint that rounds to an endpoint label is omitted.
